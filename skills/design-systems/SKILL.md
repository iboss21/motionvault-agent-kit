# Design systems

Search the appropriate MotionVault library and inspect the actual style/component preview. Use `get_design_system` for colors, typography, spacing, component rules, and DESIGN.md; use `get_asset_source` for editable code.

Select the system for the product and content density, then apply its relationships consistently. Preserve contrast, readable body sizes, focus states, and responsive layout. A palette alone is not a design system: carry type hierarchy, spacing rhythm, border/radius rules, interaction behavior, and component composition together.

Use original systems as starting points. A reference site's public visual language may inform analysis; do not label its private design files as MotionVault assets or imply an affiliation.

Use `generate_palette`, `generate_type_scale`, `generate_spacing_scale` and `generate_design_document` for explicit structured relationships. Compare bundled candidates with `compare_design_assets`. React Bits MIT + Commons Clause components and ports are reference-only for this commercial template library, not exportable source.

Verify the requested component's real behavior and export its usable source. Keep full websites, UI components, style systems, animated backgrounds, and gradients distinct in catalog counts and recommendations.
