# Repository artwork and screenshots

These files illustrate the MotionVault product and retain the [MotionVault end-project license](https://motionvault.site/license). They are not relicensed by the MIT license for the MCP server code.

- `motionvault-banner.webp`: official MotionVault social artwork,1200×630, converted from the existing `public/social-card.png`. It combines original cinematic imagery with crisp repo-rendered typography. The collage used OpenAI image_gen; it is not a Higgsfield native generation or a claim of retained signed C2PA credentials.
- `motionvault-home.webp`: actual local homepage,1440×1000.
- `motionvault-library.webp`: actual local library,1440×1000.
- `motionvault-halo.webp`: actual HALO / Nightwatch preview,1440×1000.

Screenshots were captured in native Google Chrome at `http://localhost:5188`, without an authenticated account, then converted to WebP. They depict the development version at capture time. No interface, count, endorsement, metric or badge was painted onto these captures. Current deployment/catalog contents can change.

Exact capture timestamps, source routes and sizes are in [capture-manifest.json](capture-manifest.json). Badge numbers in the repository README are factual static labels linked to the actual capability registry; they are not third-party certification or CI pass badges.
